How to Run — Step by Step
1

Clone & Upload to Databricks

  • Clone repo to your machine
  • Add to Databricks Repos (Workspace → Repos → Add)
  • Or import .py files directly into notebooks
Git / Databricks
2

Mount Your Storage

  • Create ADLS Gen2 storage account
  • Mount at dbfs:/mnt/sales-datalake/
  • Upload sample CSVs to /raw/transactions/
Azure / ADLS Gen2
3

Create Delta Live Tables Pipeline

  • Workflows → Delta Live Tables → Create
  • Point source to the three notebook paths
  • Set target schema: bronze / silver / gold
  • Run once to initialize
DLT Pipeline
4

Schedule the Job

  • Workflows → Jobs → Create Job
  • Task 1: DLT pipeline
  • Task 2: anomaly_detector.py
  • Task 3: email_alerts.py
  • CRON: 0 7 * * * (daily 7am)
Databricks Jobs
5

Set Alert Secrets

  • Databricks → Secrets → Create scope
  • Add ALERT_EMAIL
  • Add ALERT_PASSWORD (app password)
  • Add ALERT_RECIPIENTS
Databricks Secrets
6

Connect Power BI

  • Open Power BI Desktop
  • Get Data → Databricks → SQL Warehouse
  • Point to your Gold tables
  • Publish to Power BI Service
  • Set up Row-Level Security roles
Power BI
